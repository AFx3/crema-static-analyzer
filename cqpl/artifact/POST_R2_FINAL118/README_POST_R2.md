# POST_R2 FINAL118 freeze

This directory is the compact, version-controlled POST-R2 FINAL118 freeze.

Scientific interpretation:

- 118 subjects × 12 queries = 1416 attempts.
- `typed_edge_flow_v1` is present on all 118 artifacts.
- R2-vs-stripped observational neutrality is 0/1416 truth-or-assessment deltas.
- PRE_MUST→POST_R2 contains exactly 8 deltas, all `ff→unk`, confined to
  `bmulti_df_second_ffi` and `bmulti_uaf_second_ffi`.
- Those eight transitions are attributed to the Gate A/R1 restoration of
  live SVF/FFI positional evidence, not to R2 typed-edge interpretation.
- R2 preserves Normal/Unwind edge semantics but does not yet scope allocation
  events to outcomes and must not justify MAY→MUST/`tt`.

`SUBJECTS.tsv` records generation-time absolute paths. For portable integrity,
use `ANNOTATED_ICFG_SHA256SUMS.tsv`, which records the SHA-256 of every one of
the 118 annotated ICFGs together with a path relative to the generation run.

No Git tag is part of this freeze.
